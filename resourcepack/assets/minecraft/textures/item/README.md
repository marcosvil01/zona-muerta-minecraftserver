# Texturas del Resource Pack — Zona Muerta

Coloca aquí los archivos PNG de 16×16 píxeles para las armas artesanales.

## Archivos necesarios

| Archivo                   | Arma               | CMD |
|---------------------------|--------------------|-----|
| `zm_machete.png`          | Machete Oxidado    | 1001|
| `zm_cuchillo.png`         | Cuchillo Superv.   | 1002|
| `zm_hacha_oxidada.png`    | Hacha de la Horda  | 1003|
| `zm_lanza.png`            | Lanza Improvisada  | 1004|
| `zm_escudo_chatarra.png`  | Escudo de Chatarra | 1005|
| `zm_antorcha.png`         | Antorcha Improvisada | 1006|
| `zm_ballesta.png`         | Ballesta Artesanal | 1007|

## Cómo crear texturas en 16×16

Usa cualquier editor de píxeles (Aseprite, Libresprite, PixelCraft, incluso Paint):
1. Nuevo archivo → 16×16 px
2. Dibuja el arma (base oscura + detalles metálicos)
3. Exporta como `.png` con fondo transparente
4. Coloca el archivo en esta carpeta

## Herramientas sugeridas
- **Aseprite** (de pago, muy completo)
- **Libresprite** (gratuito, fork de Aseprite)
- **BlockBench** → para modelos 3D además de texturas

## Notas
- Mientras no haya texturas personalizadas, el juego mostrará el modelo de vanilla pero con nombre/lore personalizado
- El resource pack YA está correctamente estructurado; solo faltan los `.png`
